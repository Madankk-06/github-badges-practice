# 🧪 Developer Sandbox

A dedicated technical sandbox environment for prototyping ideas, testing distributed Git workflows, exploring API architectures, and conducting collaborative development experiments.

---

## 🎯 Purpose & Scope

The purpose of this repository is to serve as an isolated, lightweight staging ground to:
- **Experiment with Git Workflows:** Test complex branching strategies, merge conflict resolution, commit trailers, and multi-author pair programming models.
- **Architectural Prototyping:** Build quick proof-of-concepts (POCs) for upcoming tools, agentic flows, and backend endpoints before graduating them into standalone production repositories.
- **Collaborative Research & Discussions:** Host structured Q&A discussions on AI systems, streaming protocols (SSE), and state persistence patterns.

## 🤝 Collaboration & Conventions

When conducting exploratory work in this sandbox:
1. **Branching:** Features and tests are developed in short-lived topic branches (`feature/*`, `experiment/*`) and integrated into `main` via pull requests.
2. **Co-Authorship:** Commits produced collaboratively utilize standard Git `Co-authored-by` trailers to preserve contributor attribution.
3. **Discussions:** Technical design questions, architectural decisions, and community inquiries are tracked in the [Discussions tab](https://github.com/Madankk-06/sandbox/discussions).
